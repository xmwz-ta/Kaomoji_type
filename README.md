# 小狼毫颜文字输入助手 · 零基础安装与使用教程

输入“抱抱”“开心”“晚安”等中文时，让输入法同时推荐相关颜文字。想只发颜文字，用方向键选中它，再按 **F7**。

本项目是 **Windows 小狼毫输入法的插件**。你需要先安装小狼毫，再安装本插件；它不会直接给微软拼音、搜狗等其他输入法添加功能。

- 977 个去重颜文字，涵盖情绪、动作、动物和物品。
- 平时自动显示最多 6 个推荐；按 F8 可展开最多 36 个，并翻页选择。
- 支持前几个字联想，例如“咖”联想到咖啡，“生日快”联想到生日蛋糕。
- 安装完成后随小狼毫使用，**不用每天启动程序，也不用保持命令窗口打开**。
- 安装时需要下载软件和依赖；日常推荐在电脑本地完成，不需要联网或 API 密钥。

> 本教程以 Windows 10 / 11、官方小狼毫和“朙月拼音·简化字”方案为例。实际验证环境为 Windows 11、小狼毫 0.17.4。其他输入方案可能需要额外合并配置。

<a id="terms"></a>
## 一、先认识几个常用词

| 教程中的词 | 用普通话解释 |
| --- | --- |
| 候选栏 | 打拼音时出现的那个小框，里面有带数字的汉字或词语。 |
| 高亮 | 候选栏里当前被选中、背景颜色不同的那一项。用 ↑ / ↓ 移动高亮，还没有把字发出去。 |
| 上屏 | 把候选真正输入到记事本、聊天框等地方。通常按数字键或空格就会上屏。 |
| 输入方案 | 小狼毫里面使用的拼音或其他输入规则。本教程用“朙月拼音·简化字”。 |
| 用户文件夹 | 小狼毫存放你个人设置和词库的地方。它和小狼毫安装目录、项目下载目录是三个不同的文件夹。 |
| 重新部署 | 让小狼毫重新读取修改过的设置。每次安装或更新插件后做一次。 |

**没有写过代码也可以安装。** 下文的命令只是让电脑执行安装步骤，整行复制即可，不需要学习编程。

<a id="install"></a>
## 二、第一次安装：按顺序完成六步

### 第 1 步：安装小狼毫，并确认能正常打中文

已经在使用小狼毫的用户，可以直接确认当前输入方案，然后继续第 2 步。

1. 打开 [小狼毫官方下载入口](https://rime.im/download/)，选择 Windows 的“小狼毫”。也可以查看[本项目已验证的 0.17.4 版本](https://github.com/rime/weasel/releases/tag/0.17.4)。
2. 在 GitHub 下载页面的 **Assets** 区域选择小狼毫安装程序，通常是 `.exe` 文件。不要把 **Source code** 当作输入法安装程序。
3. 打开安装程序，按界面提示完成安装。如果安装程序提示重启或注销，请先完成该操作。
4. 打开 Windows 自带的“记事本”。可以在开始菜单搜索“记事本”。
5. 按 **Win + 空格**，在输入法列表中选择“小狼毫”。
6. 在记事本中按 **F4** 打开小狼毫的方案菜单，选择 **朙月拼音·简化字**。名称中的“朙”是“明”的异体字。
7. 输入 `nihao`，确认可以选出并输入“你好”。

如果方案菜单中没有“朙月拼音·简化字”，先从小狼毫托盘右键菜单的“输入法设定”中查找并启用它，再重新部署。不同版本的菜单文字可能略有不同。

**这一步完成的标志：记事本中能用小狼毫打出普通中文。** 如果还不能，请先解决小狼毫本身的安装问题。

方案菜单及下载说明可参阅 [Rime 官方安装说明](https://rime.im/download/)。

### 第 2 步：下载并解压本项目

1. 打开 [本项目 GitHub 首页](https://github.com/xmwz-ta/Kaomoji_type)。
2. 点击文件列表上方的绿色 **Code** 按钮。
3. 点击 **Download ZIP**。也可以[直接下载当前 main 分支 ZIP](https://github.com/xmwz-ta/Kaomoji_type/archive/refs/heads/main.zip)。
4. 下载完成后，右键 ZIP 文件，选择 **全部解压缩**。
5. 进入解压出来的文件夹。你应当能看到 `README.md`、`requirements.txt`，以及 `scripts`、`rime`、`data` 等文件夹。

> 后文把这个地方叫“项目文件夹”。不要直接在 ZIP 压缩包窗口内操作，也不要只下载某一个 Lua 文件。插件需要完整项目中的几个配套文件。

如果打开后只看到另一个 `Kaomoji_type-main` 文件夹，再进入一层，直到看见 `requirements.txt`。

### 第 3 步：安装 Python，仅用于安装和更新插件

Python 是运行安装工具的软件。**安装本插件时需要，日常打字不需要启动。**

1. 打开 [Python 官方 Windows 下载页面](https://www.python.org/downloads/windows/)。
2. 本教程建议选择 **Python 3.13 系列的 Windows installer (64-bit)**，适用于常见 Intel / AMD 64 位 Windows 电脑。不要选择 embeddable package 或 source archive。其他架构请选对应安装程序；本项目未逐一验证 ARM 设备。
3. 打开安装程序。如果首页有 **Add python.exe to PATH**，勾选它，再进行安装。
4. 安装完成后关闭之前打开的终端窗口，下一步重新打开。

如果已经安装 Python 3.11 或更高版本，可以先用下一步的版本检查确认，无需重复安装。项目实际测试过 Python 3.11 和 3.13。

### 第 4 步：找到小狼毫的用户文件夹

1. 在屏幕右下角通知区域找到小狼毫图标；看不到时，先点展开隐藏图标的小箭头。
2. 右键小狼毫图标，点击 **用户文件夹**。
3. 文件资源管理器打开后，点击上方地址栏，复制完整路径。
4. 暂时把路径保存在记事本里，下一步安装时要粘贴。

常见路径类似：

```text
C:\Users\你的用户名\AppData\Roaming\Rime
```

**不要直接照抄上面的示例。** 你的电脑可能使用其他位置，以小狼毫实际打开的文件夹为准。

这一步还可以把整个用户文件夹复制一份到其他位置作为备份。安装工具也会为它修改的已有文件生成备份。

### 第 5 步：打开 PowerShell，运行安装工具

#### 5.1 在正确位置打开窗口

1. 回到第 2 步的“项目文件夹”。
2. 点击文件资源管理器上方的地址栏，输入 `powershell`，按回车。
3. 会打开一个 PowerShell 窗口。后面的命令都粘贴到这个窗口中。

不需要以管理员身份运行，也不需要双击任何 `.py` 文件。下面每个框复制一行，按一次回车，等待执行结束后再继续。

#### 5.2 检查 Python

```powershell
python --version
```

正常会显示类似 `Python 3.13.x` 的版本号。

如果提示找不到 `python`，或打开了 Microsoft Store，先看[常见问题](#faq)。确认 Python 可用后再继续。

#### 5.3 创建本项目自己的安装环境

```powershell
python -m venv .venv
```

成功时可能没有任何提示，只是回到可以继续输入命令的位置。项目文件夹会新增 `.venv` 文件夹。

然后安装安装器需要的依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

这一步需要联网。等待结束，通常能看到 `Successfully installed`；如果已经装过，也可能显示 `Requirement already satisfied`。出现红色报错时先解决，不要继续下一步。

#### 5.4 填入用户文件夹并安装

先复制这一行：

```powershell
$rimeUserDir = Read-Host "请粘贴小狼毫用户文件夹的完整路径，然后按回车"
```

它会停下来等待你输入。现在粘贴第 4 步复制的路径，**不要在路径两边加引号**，再按回车。

接着运行：

```powershell
.\.venv\Scripts\python.exe scripts\install_rime.py --user-dir "$rimeUserDir" --schema luna_pinyin_simp
```

这条命令针对本教程的 **朙月拼音·简化字**。其中 `luna_pinyin_simp` 是该方案的内部名称，直接保留即可。

正常结束时会列出写入的文件和备份，最后出现：

```text
Redeploy Weasel. Recommendations run locally; no Python service is required.
```

意思是：“请重新部署小狼毫。推荐在本地运行，不需要启动 Python 服务。”

**看到这句话后，就不用再运行 `server.py` 或 `start_service.ps1`。** 安装输出中的 `ipc_dir` 是保留的旧接口字段，普通用户不用处理它。

如果出现 `Installation failed`，请先看常见问题，不要反复复制文件覆盖原配置。

### 第 6 步：重新部署，让插件生效

1. 右键屏幕右下角的小狼毫图标。
2. 点击 **重新部署**。
3. 等部署完成，再回到记事本。
4. 确认当前仍使用小狼毫、“朙月拼音·简化字”，并处于中文模式。

**安装完成。PowerShell 可以关闭。** 下次开机照常切换到小狼毫即可使用，不用重复这六步。

<a id="first-use"></a>
## 三、第一次试用：确认安装成功

建议先在记事本中测试，避免聊天软件抢占快捷键。

### 试验 A：出现推荐并正常输入

1. 输入拼音 `baobao`，先不要按空格或数字键。
2. 看候选栏中的中文。如果首选是“抱抱”，通常能直接看到相关颜文字推荐。
3. 如果首选不是“抱抱”，使用 ↑ / ↓，必要时翻页，**高亮“抱抱”**，然后按 **F8**。
4. 现在应出现与“抱抱”对应的颜文字候选。
5. 按某个候选前的数字，通常会输入“抱抱 + 颜文字”。

例如可能看到类似：

```text
抱抱 ⊂(・▽・⊂)
```

具体图案和顺序可能不同，这是正常的。

### 试验 B：只输入颜文字

1. 再次输入 `baobao`，找到“抱抱”的颜文字候选。
2. 用 ↑ / ↓ **高亮带颜文字的那一项**。
3. 按 **F7**。

这次只会输入颜文字，不会输入“抱抱”。当前还没上屏的中文组合会取消；已经在记事本里的文字不会被删除。

> 按 F7 前不要先按数字或空格，否则候选已经上屏，F7 无法再去掉前面的中文。F7 只有在高亮本插件的颜文字候选时才生效。

<a id="usage"></a>
## 四、日常操作与快捷键

| 你想做什么 | 操作 | 结果 |
| --- | --- | --- |
| 中文和颜文字一起输入 | 按颜文字候选前的数字，或高亮后按空格 | 输出中文和颜文字。 |
| **只输入颜文字** | **高亮颜文字候选，再按 F7** | 只输出该颜文字。 |
| 看更多相关颜文字 | 高亮想要的中文候选，按 F8 | 展开最多 36 个推荐。 |
| 下一页 / 上一页 | PageDown / PageUp | 翻页，不直接上屏。 |
| 换一个高亮候选 | ↑ / ↓ | 移动选中项，不直接上屏。 |
| 关闭当前输入组合 | Esc | 取消本次还没上屏的内容。 |
| 临时关掉 / 再打开推荐 | F9 | 当前输入会话开关，不修改永久配置。 |
| 清除当前会话的推荐记忆与缓存 | Shift + F9 | 一般不需要使用；部分 Shift 切换设置下可能不方便。 |

**F7 是当前“只输出颜文字”的快捷键。以前的 Shift + Enter 已取消。**

如果笔记本的 F7 会调音量、亮度或触发设备功能，尝试 **Fn + F7**；F8、F9 同理。是否需要 Fn 取决于键盘设置。

### 普通模式和展开模式有什么区别？

- **普通模式：** 通常保留前 3 个中文候选，再插入最多 6 个推荐。自动推荐依据首选中文；主题相关颜文字较少时数量会减少。
- **展开模式：** 高亮中文后按 F8，推荐绑定这个中文，颜文字排到前面，最多 36 个，可翻页。并非每个词都有 36 个。
- 展开后，如果当前高亮的是颜文字，再按 F8 可返回普通模式。修改拼音也会解除原来的中文绑定。

### 中文已经输入了，还能补颜文字吗？

可以。在最近一次普通中文上屏后的 **30 秒内**，按 F8，会打开只包含颜文字的补充入口，选择后不会重复那段中文。

这个入口只记得最近一次通过当前小狼毫会话提交的中文，不会读取聊天框中所有历史内容。逐字输入时，它可能只知道最后一个字。

<a id="completion"></a>
## 五、前几个字联想与同音字选择

### 不用每次把触发词打完

前缀联想针对的是**中文候选的前几个字**，不是任意英文字母或任意拼音缩写。

| 中文候选中出现的内容 | 可以联想到 |
| --- | --- |
| 抱 | 拥抱、抱抱 |
| 咖 | 咖啡 |
| 晚 | 晚安、睡觉 |
| 生日快 | 生日快乐、蛋糕 |
| 摸摸 | 摸头 |
| 笑不活 | 大笑 |
| 我想喝咖 | 咖啡 |

候选注释可能显示 `联想：咖啡`。这是告诉你“这个颜文字来自咖啡主题”，**不会自动把你写的“咖”补成“咖啡”**。

- 普通方式选择：保留“咖”，追加颜文字。
- 高亮后按 F7：只输出颜文字。

完整词匹配优先。“我”“好”“太”等单独输入时含义太宽，不保证有前缀联想。否定表达也会尽量过滤；它不是能理解所有句子的人工智能模型。

### 同音字出现时，怎样指定目标？

例如你输入 `ku`，候选里可能同时有“苦”“哭”“酷”“库”，顺序因个人词频而异。

1. 先用 ↑ / ↓ 移动到想表达的那个字，例如“哭”。
2. **不要按数字或空格确认中文。**
3. 按 F8，展开对应“哭”的推荐。
4. 数字键选中可输出“哭 + 颜文字”；高亮颜文字后按 F7 可只发颜文字。

F8 绑定的是你当时高亮的实际中文候选。只移动中文高亮、还没按 F8 时，普通推荐仍可能来自第一项。

### 可以试试这些词

| 类别 | 例子 |
| --- | --- |
| 情绪 | 开心、委屈、气死了、笑不活了、太离谱了、终于成功了、笨、小笨蛋、坏蛋 |
| 动作 | 抱抱、亲亲、摸摸头、鼓掌、睡觉、吃饭、学习、开黑、打你、捶捶你 |
| 动物 | 猫、狗狗、兔子、熊猫、小熊猫、海獭、小鱼 |
| 物品或场景 | 蛋糕、咖啡、鲜花、礼物、下雨、星星 |

## 六、常见问题

### 1. 输入 `python --version` 提示找不到命令，或打开商店

先试：

```powershell
py --version
```

如果它正常显示 3.11 或更高版本，可把第 5 步创建环境的命令换成：

```powershell
py -m venv .venv
```

后续使用 `.\.venv\Scripts\python.exe` 的命令保持原样。如果 `python` 和 `py` 都不可用，重新检查 Python 安装，随后关闭并重新打开 PowerShell。

### 2. 找不到 `requirements.txt` 或 `scripts/install_rime.py`

通常是 PowerShell 打开的位置不对，或项目还没解压。

关闭窗口，进入同时能看到 `requirements.txt` 和 `scripts` 的文件夹，在地址栏输入 `powershell` 重新打开，再执行安装步骤。

### 3. 提示找不到 `.venv\Scripts\python.exe`

先确认创建环境的命令 `python -m venv .venv` 已成功执行，且当前仍在同一个项目文件夹。如果之前出现了报错，应先处理该报错。

本教程不要求执行 `Activate.ps1`，无需为此修改 PowerShell 的执行策略。

### 4. 下载依赖失败，或提示没有 `yaml` / `lupa`

确认网络可用，在项目文件夹重试：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

安装插件时也要使用 `.\.venv\Scripts\python.exe`，不要中途换成另一个 Python。如果出现需要编译或找不到适配安装包的错误，请记录 Python 版本和报错；本教程优先使用常见 64 位 Python 3.13。

### 5. 安装器提示用户目录不存在

重新从小狼毫托盘打开“用户文件夹”，复制其地址。不要选小狼毫 `.exe` 所在的安装文件夹，也不要选项目下载目录。

重新执行 `$rimeUserDir = Read-Host ...` 那一步，粘贴真实路径时不要加额外引号，再执行安装命令。

### 6. 提示 `Existing patch conflicts` 或重复 YAML 键

这表示已有设置与插件要添加的设置冲突，或者配置中出现重复项目。安装工具会停止，避免直接覆盖已有插件。

不要删除整个配置文件。先保存报错和备份，到[项目 Issues](https://github.com/xmwz-ta/Kaomoji_type/issues)说明当前输入方案与已有插件，请求帮助合并。

### 7. 安装成功了，但没有颜文字

按这个顺序检查：

1. 用记事本测试，确认当前输入法是“小狼毫”，不是微软拼音。
2. 按 F4，确认正在使用安装命令对应的“朙月拼音·简化字”。
3. 确认处于中文模式，能出现普通中文候选。
4. 确认安装后点过托盘菜单的“重新部署”，并等待完成。
5. 如果之前按 F9 关闭过推荐，再按一次打开；也可重启输入法后重试。
6. 用 `baobao` 测试，高亮“抱抱”后按 F8。
7. 仍无效时，检查用户文件夹下 `lua` 文件夹里是否同时存在 `kaomoji.lua`、`kaomoji_local.lua`、`kaomoji_data.lua` 三个文件。

其他方案不一定会自动启用插件。`luna_pinyin_simp` 只对应本教程的方案，不能原封不动用于所有双拼或第三方方案。

### 8. F7 没反应，或输出了中文

F7 前必须高亮**带颜文字的候选**。高亮普通汉字时，插件不会执行“只输出颜文字”。

不要先按数字或空格上屏。笔记本尝试 Fn + F7，并先在记事本测试。如果只有某个软件失效，可能是该软件占用了快捷键。

### 9. 按 Shift 会退出中文输入

这是部分小狼毫配置的中英文切换行为。只发颜文字请使用 **F7**，不需要按 Shift。不要使用旧教程中的 Shift + Enter。

### 10. 看不到更多候选，或想换一页

普通模式只展示少量推荐。先高亮中文按 F8 展开，再用 PageDown / PageUp 翻页。小型键盘可能需要 Fn 组合键。

977 是整个词库的总数，不是每次都列出 977 个。系统会筛选与输入相关的内容。

### 11. 图案出现方框或字符不整齐

颜文字使用了多种 Unicode 字符。显示效果取决于 Windows 字体和接收文字的软件，部分应用可能缺字。先比较记事本与目标软件中的显示效果；这与插件有没有匹配到候选是两件事。

### 12. 每次开机都要运行 Python 吗？

不用。安装并重新部署后，默认推荐直接在小狼毫内部运行。可以关闭 PowerShell，不需要启动服务器。

<a id="maintenance"></a>
## 七、更新、调整数量与停用

### 更新到 GitHub 最新版本

1. 重新下载首页的 ZIP，并解压到一个新文件夹。
2. 在新项目文件夹中打开 PowerShell。
3. 按第 5 步重新创建 `.venv`、安装依赖、填写同一个小狼毫用户文件夹并运行安装器。
4. 在小狼毫托盘菜单点“重新部署”。

安装器会为这次被改动的已有文件生成新的备份。只下载 ZIP 或只修改项目文件，并不会自动更新正在运行的小狼毫。

### 调整每次显示的数量（可选）

默认设置通常够用。确实想修改时：

1. 在小狼毫“用户文件夹”中找到 `luna_pinyin_simp.custom.yaml`。
2. 先复制这个文件留作备份，再用记事本打开。
3. 查找已有的 `kaomoji/auto_count` 和 `kaomoji/expanded_count`，只修改数字，不要重复粘贴一整份 `patch:`。
4. 保存为原文件名并重新部署。

| 配置项 | 默认值 | 允许范围 | 含义 |
| --- | --- | --- | --- |
| `kaomoji/auto_count` | 6 | 1–12 | 普通模式最多推荐几个。 |
| `kaomoji/expanded_count` | 36 | 6–64 | F8 展开后最多推荐几个。 |
| `menu/page_size` | 9 | 本教程保持 9 | 每页总候选数量，不是整个词库数量。 |

安装器更新时会重新应用项目默认值，自定义数量可能需要再次修改。文件名必须保持 `.yaml`，不要保存成 `.yaml.txt`。

### 临时停用

按 **F9**。再按一次恢复。它只是当前输入会话开关，不是全局永久卸载。

### 长期停用

打开当前方案的 `.custom.yaml` 文件，把已有的：

```yaml
kaomoji/enabled: true
```

改为：

```yaml
kaomoji/enabled: false
```

保存并重新部署。配置项有引号时保留引号即可，其他内容不要改。以后更新插件可能重新设为开启。

### 回到安装前的配置

安装器会在原文件旁创建类似下面的备份：

```text
rime.lua.kaomoji-backup-日期时间
luna_pinyin_simp.custom.yaml.kaomoji-backup-日期时间
```

先另存当前配置，再选择**同一次安装时间**对应的备份，复制并恢复为原文件名，最后重新部署。更新前备份恢复的是上一个版本；要回到从未安装插件的状态，需要第一次安装前的备份。

如果某个文件第一次安装前不存在，就不会有它的旧备份。对于无法确认的配置，优先用上面的“长期停用”，或提供文件情况请求协助。**不要为卸载插件删除整个 Rime 用户文件夹或个人词库。**

<a id="development"></a>
## 九、给开发者的说明

普通用户不需要阅读这一节，也不用运行下面的命令。

### 数据与生成

- [data/collections.json](data/collections.json)：扩展颜文字及主题。
- [data/lexicon.json](data/lexicon.json)：触发词与情绪规则。
- [scripts/build_offline.py](scripts/build_offline.py)：生成共享词库和前缀索引，以及 Lua 数据文件。
- [rime/example.custom.yaml](rime/example.custom.yaml)：安装器使用的方案配置。

```powershell
.\.venv\Scripts\python.exe scripts\build_offline.py
.\.venv\Scripts\python.exe -m pytest -q
```

生成后需重新安装并部署。不要单独运行 `build_demo_data.py` 更新发行词库，它只生成基础数据。

### 独立 API

```powershell
.\.venv\Scripts\python.exe python\server.py
```

可选 HTTP API 监听 `127.0.0.1:8765`，`POST /recommend` 接收 `text`、`top_k`（1–64），以及可选的 `context`、`recent`。API 默认返回 3 个兼容旧客户端，和小狼毫默认 6 个不同。

默认 Lua 插件不依赖这个服务。Python 与 Lua 共享词库和前缀索引，但 Python 另有正则规则与更丰富的解释分数，排序不保证完全一致。

### 验证与边界

当前版本 233 项自动测试通过；真实小狼毫 DLL 与完整拼音词库已验证离线推荐、同音候选锁定、分页、上屏以及 F7 只输出颜文字。

详见[验收记录](docs/verification.md)、[架构说明](docs/architecture.md)和[情绪识别说明](docs/nlp.md)。实际 DLL 测试为隔离引擎测试，不代表已经逐个测试所有 Windows 软件窗口及字体。情绪识别使用规则，复杂反话和长距离指代仍可能误判。
