# 当前架构（本地版）

小狼毫默认加载 kaomoji.lua → kaomoji_local.lua → kaomoji_data.lua。数据只在模块加载时载入；普通输入同步进行有界短语检索、主题筛选及多样性排序。缓存最多 32 个查询，退出会话释放。无 HTTP、子进程、心跳文件或后台定时器依赖。

普通模式使用首选中文及其前面已转换的分段，插入 6 个推荐。F8 在 processor 中读取 get_selected_candidate 和 get_commit_text，保存所选中文、候选范围与当前原始编码；刷新后 filter 使用这个快照。filter 不读取活动菜单，避免重入。修改编码、提交或关闭功能时解除快照。

展开模式推荐排在前面，默认最多 36 个，由 Rime 标准候选菜单分页。只在当前候选范围内追加颜文字，前面确认过的分段由 Rime 保留。commit_notifier 保存最近一次普通中文提交，30 秒内 F8 打开 km 翻译器，只提交颜文字。

分析区分情绪分数、动作、动物和物品。否定降低情绪权重并抑制否定动作；转折前分句降权；特殊短语抑制冲突情绪。单字猫/狗/熊/哭/酷等用完整短句匹配，避免猫腻等误触发。

Python 的分析、HTTP API 和旧 IPC 桥保留作为独立开发接口，不是本地输入链路的必需部分。本地与 Python 使用共享扩展短语和词库，但 Python 另保留旧正则规则、意图、语气与完整分数解释，不能保证每项排序完全一致。

已使用真实 Weasel 0.17.4 DLL 和完整 luna_pinyin_simp 验证选中同音候选后的 F8、分页及实际上屏。Rime 无法读取任意应用光标前后的全文，因此本插件不声称理解整篇文档。
